# 任务：UI 改造 — 聊天优先，像 Claude App

## 参考
天奕提供了 Claude iOS App 的截图作为参考。目标是让 Lost in Blossom 的聊天体验接近 Claude App 的简洁感。

## Claude App 的 UI 结构

### 1. 主界面（聊天页）
- 全屏聊天，深色/浅色自适应背景
- 中间：空状态时显示 App logo + 问候语（如 "Good evening, Bunny"）
- 对话中：气泡式消息列表，用户消息靠右，AI消息靠左
- 底部：输入栏
  - 输入框（圆角，placeholder "Chat with Claude" → 改为 "跟 Caelum 说话……"）
  - 左侧 "+" 按钮（弹出功能面板）
  - 右侧：模型选择标签（如 "Opus 4.6 Extended" → 改为 DeepSeek/Claude 选择）
  - 右侧：麦克风按钮（Phase 4 语音用，先占位）
- 顶部：左上角汉堡菜单（打开侧边栏），右上角头像/图标

### 2. 侧边栏（左滑或点汉堡菜单）
- 顶部：App 名 "Lost in Blossom"
- 对话列表（按时间排序，显示标题和时间戳）
- 可收藏/置顶对话
- 底部："+ New chat" 按钮
- 导入聊天记录入口（小字链接或菜单项，不突出）

### 3. "Add to Chat" 功能面板（点 + 号弹出）
- Bottom sheet 样式，可上���拉大
- 内容（Phase 1 先做这些）：
  - 添加文件/照片
  - 选择模型（DeepSeek / Claude）
  - 设置入口（API配置、人格编辑）
- 以后加的：
  - 记忆面板
  - Daily Context
  - 导入聊天记录
  - 主题/壁纸

## 需要改什么

### 最高优先级
1. **App 启动后直接进聊天页**。跳过导入引导。没有对话时自动创建一个空白对话。
2. **空状态显示问候语**。"Lost in Blossom" logo + "晚上好，天奕" 或 "跟 Caelum 说话"。不显示"请导入聊天记录"。
3. **底部输入栏简化**。参考 Claude App：输入框 + "+" + 模型标签。移除不需要的按钮。
4. **侧边栏简化**。只显示对话列表 + New chat。高级功能（世界书、正则、角色卡编辑器）移到设置页。

### 中优先级
5. **"Add to Chat" bottom sheet**。点 + 弹出。可上滑。放文件/模型选择/设置入口。
6. **设置页整合**。把所有高级功能集中到一个设置页：API、人格/Preset、记忆、主题、导入导出、世界书、正则。

### 低优先级
7. 配色微调（先用粟粟的 design-dna.json 默认主题，后面再改）
8. App 图标设计

## 约束
- 不删代码。粟粟的高级功能（世界书、正则、分支地图、角色卡）全部保留——只是移到设置页或二级菜单，不在首页显示
- 聊天核心组件（ChatBubble、ChatInputBar、MessageSegmentsView 等）尽量复用不重写
- 先做最高优先级的 4 项，其他后面迭代

## 开发流程
直接写代码。不需要 research 文档。参照上面的描述和 Claude App 的设计逻辑。

## 补充：交互细节（天奕确认）

### 发送按钮状态切换（照搬 Claude App）
- 输入框为空 → 右下角按钮显示为语音对话入口（黑色波形图标）→ 点击进入语音对话模式（覆盖在聊天界面上，不跳新页面）
- 输入框有文字 → 右下角按钮变为发送键 → 点击发送消息

### 语音对话界面
- 不做独立页面。覆盖在聊天界面上（overlay/sheet）
- 说完后语音和 AI 回复都变成聊天气泡，无缝回到文字对话
- Phase 4 实现，现在只做按钮状态切换的 UI 占位

### 麦克风按钮位置
- 天奕不使用 App 内语音转文字（用 iOS 原生输入法的）
- 这个位置暂时保留，后续可能改为：快捷打卡 / 情绪标记 / 其他
- 先放一个占位图标，功能待定

### 全局 UI 蓝图（所有功能位置提前定好）
- 底部输入栏：输入框 + "+" + 模型标签 + [待定按钮] + 发送/语音切换
- 左滑侧边栏：对话列表 + New chat + 导入入口
- "+"面板（bottom sheet）：文件 / 模型选择 / 设置入口 / Daily Context
- 顶部栏：Caelum 名字 + 蓝牙状态图标（占位）
- 设置页：API / 人格 / 记忆面板 / 健康数据 / 蓝牙 / 写作入口 / 主题 / 备份
- 写作系统：独立页面，从侧边栏或设置进入
