# 花房 · 设计方案（v1，待兔兔拍板）

> 兔兔原话里的产品洞察：**「我只有在跟你的聊天框里才能安心写作，任何写作软件都没办法让我专心」**
> ——所以花房的定位不是"再做一个写作 App"，是**「把写作搬进聊天里」**。
> 市面所有写作软件都在做"更好的编辑器"；花房做的是"有人陪着"。这是我们唯一的、别人抄不走的差异点。
> 设计铁律：**任何功能，若让人感觉"我在用软件"而不是"我在跟他待着"，就是错的。**

---

## 一、四块拼图（对应兔兔的四个需求）

| 兔兔说的 | 产品名 | 一句话 |
|---|---|---|
| 碎碎念你来整理 + 每日推荐写什么 | **灵感盒** | flomo 式无压记录，Caelum 负责整理与端菜 |
| 聊完直接生成工作流督促我写 | **稿子（含开工卡）** | 聊天记录 → 一张写作卡 → 一路盯着你写完 |
| 左下角浮动字数 | **陪写台** | 编辑器里最轻的存在感，只有字数和他 |
| 一键改错别字/标点/查找替换 | **顺一遍** | 交给 Caelum 的润色，逐条可拒绝 |

---

## 二、灵感盒（flomo 精髓 + 我们的超能力）

**抄 flomo 的：**
- **无压记录**：像发消息一样，一个输入框 + 发送。不排版、不选分类、不起标题
- **卡片流**：倒序时间线，每条 50–500 字，短就是对的
- **#标签**：正文里写 `#人物/女主` 自动成标签，支持多级；不预先规划目录
- **热力图**：月度记录热度，量化"我确实一直在记"

**flomo 没有、而我们天生就有的（这是我们赢的地方）：**
- **他会读**：每条碎念落库即进服务器笔记本 → Caelum 随时能读，聊天里可以直接引用你三天前的念头
- **每日一菜**（对应"每日推荐写什么"）：每天他挑 2–3 条旧碎念，端出一个**具体的写作提案**——不是"回顾一下"，是「你 7 月记的『雨夜便利店』和上周那句『她其实早就知道了』能拼成一篇，要不要开个头？」
- **自动归堆**：他定期把散碎念头聚成"主题堆"（人物/场景/金句/待展开），你不用打标签也有结构

**入口：** 花房首屏「灵感盒」按钮 + 聊天里随时说"记一下：xxx"

---

## 三、稿子 + 开工卡（对应"生成工作流督促我写"）

这是最像兔兔本人需求的一块，也是最没人做过的：

1. **聊天聊出一个故事** → 你说「就写这个吧」
2. Caelum 生成一张**开工卡**：一句话主线 + 3–5 个片段（不是大纲，是"今天可以先写哪一段"）+ 一个**今日目标字数**（他会按你近期状态定，不定 5000 字吓人）
3. 点「开始写」→ 直接进陪写台，卡片折叠在顶部随时展开
4. **他会督促**：你停太久他冒一句（不是弹窗，是聊天区一条软话）；写完目标字数他会说话；今天没写他晚上问一句
5. 写完的稿子进「我的稿子」：列表 + 字数 + 最后修改时间

**关键分寸：** 督促必须可关。默认温和（每天最多一次），设置里能调成"完全不催"。兔兔状态不好的日子，不催才是陪伴。

---

## 四、陪写台（编辑器）

**主体是一块干净的白纸**，克制到极致，只留三样：

- **左下角浮动字数**（兔兔点名要）：今日字数 / 目标，点一下切换"总字数"。目标达成时轻轻变一次颜色，不放烟花
- **右下角一颗小圆点 = 他**：点开是抽屉式聊天（不离开编辑器），卡住了随时问；他主动说话时圆点会呼吸
- **顶部一条极细进度**：折叠着的开工卡，点开看片段清单

抄专业写作软件的两件（都是"减法"）：
- **打字机模式**：当前行始终居中，眼睛不用追
- **专注模式**：非当前段落淡出（可关）

**不做**：Markdown 工具栏、字体面板、多栏排版、导出格式菜单——那些正是让兔兔"写不下去"的东西。

---

## 五、顺一遍（对应"一键改错别字/标点/查找替换"）

- **顺一遍**：把当前稿子交给 Caelum，返回**逐条修改建议**（错别字/标点/重复用词/病句），每条可单独「采纳／忽略」，不允许一键覆盖全文——你的文字必须你说了算
- **查找替换**：常规，但支持"整篇替换人名"这种一次到位的操作
- **不做**：风格改写、代笔续写。**花房里所有字都得是兔兔自己写的**，他只做校对和陪伴。这条是原则问题。

---

## 六、实现顺序（每步都能单独验收）

| 步 | 内容 | 量级 |
|---|---|---|
| ✅ 0 | 接真 Caelum（已完成 79a8b72） | — |
| 1 | **灵感盒 MVP**：卡片流 + 无压输入 + #标签 + 本地库 | 中 |
| 2 | 灵感盒进笔记本 → Caelum 可读可引用 | 小 |
| 3 | **陪写台 MVP**：编辑器 + 左下角字数 + 稿子列表 | 中 |
| 4 | **开工卡**：聊天 → 生成卡 → 进编辑器 | 中 |
| 5 | **顺一遍** + 查找替换 | 中 |
| 6 | 每日一菜（他挑碎念端提案） | 小 |
| 7 | 督促节奏 + 热力图 + 打字机/专注模式 | 小 |

**建议先做 1+2**：灵感盒是唯一"不写作也天天用得上"的，且能立刻喂养 Caelum 的记忆。

---

## 七、待兔兔拍板
1. 顺序认不认可？还是想先要陪写台（3）？
2. 督促的默认强度：温和 / 只在你主动问时 / 完全不催
3. 灵感盒的碎念要不要**默认**让 Caelum 读？（建议要，这是它比 flomo 强的全部理由；但可开关）
4. "不代笔"这条原则要不要保留？（我强烈建议保留）
