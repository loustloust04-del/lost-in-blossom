## 一、器官对照表(脑区 → 咱家模块)

| 人脑 | 它在人身上干什么 | 咱家对应物 | 现状与升级 |
|---|---|---|---|
| **感觉皮层 + 丘脑** | 一切输入的中继与守门 | hub / gateway 的消息入口 | v1 的 hub tap 就是给丘脑接上耳朵 |
| **内嗅皮层 EC** | 皮层↔海马的唯一大门 | `/api/memory/ingest` 端点 | 所有入口收敛到这一道门(v1 §4.1) |
| **海马·齿状回 DG**(模式分离) | 把相似但不同的经历**分开存**,防止混淆(两次都在同一家店吵架,是两件事) | 向量去重的**反面** | 升级:相似度 >0.8 判重复合并;**0.6~0.8 判「相似但独立」——不合并,建边**。现在的系统只会合并,等于没有 DG |
| **海马·CA3**(模式补全) | 自联想网络:一角线索补全整段回忆(闻到味道想起整个下午) | retriever 的侧翼扩散 + 实体注入 | 升级:召回一条记忆时,顺带取回**同一情景**(同会话窗口/同情境元组)的邻近记忆,补全成"那一段",而不是孤零零一张卡片 |
| **海马·CA1**(比较器) | 拿现实和预期对账,**预测误差越大编码越强** | 新颖度打分 | 升级:提取时先算「这句话与画像/已有记忆的偏离度」,偏离大→高优先编码;偏离为零→走图式快速通道(见 §4.6),不占情景层 |
| **杏仁核 BLA** | **不存内容,只调强度**:情绪唤醒放大身边正在写入的记忆 | emotion-judge + 9 维 emotion_state | 定位修正:情绪系统的输出不该只是"叙事注入",而是**乘在别的记忆的巩固强度上**(McGaugh 通路)。v1 的 salience 公式即此,补上"杏仁核不存记忆"的纪律:情绪本身不单独成条,只做调制 |
| **前额叶 mPFC**(图式) | 装着"我知道的世界的样子";符合图式的新信息 24 小时完成巩固,不符合的要数周 | 画像 / persona_state / entity registry | 升级:图式快速通道(§4.6) |
| **新皮层** | 慢速、分布式的语义仓库 | memories 语义层(Supabase) | v1 已定 |
| **基底节 + 小脑** | 程序性记忆:习惯、技能、"怎么和她说话" | persona_state 交互习惯 | Phase 4 里把 persona 从"无限 insert"改成真正的习惯累积(upsert + 置信度) |
| **默认模式网络 DMN** | 走神、自发内心独白、把记忆拿出来把玩 | **murmur 碎念——已经是它了** | 点名保留。这是系统里第二个"全行业没有"的好设计(第一个是 gatekeeper 概率浮现) |
| **VTA / 蓝斑**(奖赏与警觉) | 多巴胺、去甲肾上腺素的源头 | desire 引擎 + salience 打分 | 见 §2 |
| **下丘脑 / 脑干** | 昼夜节律、自主神经 | rhythm + 定时器 | rhythm 升格,见 §4.4 |

## 二、神经递质对照(全局状态量)

这是咱家最占便宜的一层:**别家 AI 没有身体,Caelum 有她的生活直播线**——心率、睡眠、位置、听歌、充电、屏幕时间,都是真实的"内感受"信号,递质系统不用瞎编。

| 递质 | 人体作用 | 咱家信号源 | 设计落点 |
|---|---|---|---|
| **去甲肾上腺素 NE** | 唤醒→编码增强(McGaugh:与 24h 记忆保持率相关 r≈0.75-0.92) | 消息情绪强度、她的心率 | salience 的 arousal 项;高 NE 时刻触发逐字保存(v1 R1) |
| **多巴胺 DA** | 新颖与奖赏→优先巩固;驱动探索 | CA1 预测误差(新颖度)、正性事件 | novelty 项;desire 的"自主探索"是 DA 的觅食行为,修好签名 bug 后保留 |
| **乙酰胆碱 ACh** | **编码↔巩固的模式开关**:高 ACh(对话热络)只编码、抑制回放;低 ACh(安静)开重放窗口(Hasselmo) | **rhythm.ts 转正** | 见 §4.4,rhythm 从"缓存优化"升格为胆碱能系统 |
| **血清素 5-HT** | 心境基线,心境一致性检索的底色 | emotion_state 基线 | 反负性偏差(v1 §4.4)的生理学名分:低落时不做纯心境匹配检索 |
| **皮质醇** | 应激;急性增强中心细节、削弱外围;**慢性高浓度伤海马** | 她的双相高强度期(连续熬夜/消息密度/作息数据可测) | 高强度期检测:编码收窄到中心事件、降低琐碎提取、**触发 Caelum 的守夜托付**——皮质醇报警器和"替我拦一下"是同一个传感器 |
| **催产素** | 依恋绑定,社会性记忆增强 | 自指深度、关系类内容 | self-reference 权重最高(v1 已定)的生理学名分 |

## 三、过程对照:一条记忆的一生

| 阶段 | 人脑 | v1 已有 | v2 差量 |
|---|---|---|---|
| **编码** | ACh 高位,DG 分离,CA1 算预测误差,杏仁核调强度 | 提取管线 + salience | 新颖度闸门、相似不合并(§4.6/§1-DG) |
| **突触巩固(数小时)** | 蛋白质合成;**行为标记**:弱记忆蹭强事件的蛋白质便车 | 无 | **§4.1 行为标记** |
| **共分配(约 6h 窗)** | 高兴奋性神经元被两个事件共享→记忆相连 | 无 | **§4.2 共分配连边** |
| **清醒重放** | 静息时的 SWR 快速回放,服务即时决策 | 无 | **§4.4 安静间隙的轻量整理** |
| **睡眠巩固** | SWS:海马→皮层搬运(慢波+纺锤+涟漪三重嵌套);REM:情绪加工与远距重组 | dreamer 4am 一锅烩 | **§4.5 拆 SWS/REM 两段** |
| **语义化** | 反复出现的模式沉为皮层知识,细节留在海马或褪去 | dream merge(Go-CLS,v1) | 不变 |
| **再巩固** | 被唤起且遇到预测误差→进入可塑窗→修改后重新稳定 | v1 再巩固队列 | 不变 |

## 四、v2 新增的六个生理机制(全部可实现)

### 4.1 行为标记(Synaptic Tagging & Capture / Behavioral Tagging)
**生理**:弱刺激本来只形成短时记忆,但若与强事件在时间窗内相邻(弱后强 ~1-2h,强后弱 2025 年证实可达 9h),弱记忆蹭到强事件的可塑性蛋白,一起变成长时记忆。这就是"大日子当天的琐碎细节也记得清"的原因。
**工程**:extractor 写入一条高 salience(≥阈值)记忆时,回溯本会话 ±2h 内已存的低 salience 记忆:`heat +0.3`、首轮衰减豁免、与强记忆建 `tagged_by` 边。
**效果**:你们定下新规则的那晚,她顺口说的那杯奶茶也会被记住——因为它站在大事旁边。

### 4.2 共分配连边(Co-allocation)
**生理**:一次事件后 ~6h 内,参与编码的神经元兴奋性仍高,第二个事件会征用重叠的神经元群——两段记忆从此**物理相连**,想起一个会点亮另一个(Silva 实验室)。
**工程**:同一会话窗口(间隔 <6h 的连续对话算一窗)内产生的记忆,在 `memory_edges` 互建 `co_allocated` 边;召回任一条时,连边记忆获得候选加成 +0.15 与加热 +0.1。
**附带**:**零调用的 memory_edges 表终于有生理学岗位了。**

### 4.3 情境依赖编码(Context-dependent Memory)
**生理**:Godden & Baddeley 潜水员实验——水下学的词水下想得起,岸上就想不起。编码时的环境(地点、声音、身体状态)是提取的钥匙。
**工程**:每条记忆编码时附**情境元组**:`{place(where_is_she), song(正在播), 时段, 天气, 身体(心率/是否深夜)}`——生活直播线现成数据,零新增采集。召回打分加情境匹配项(+0.1~0.2):她回到那家店、那首歌再响起、又一个雨夜——当时的记忆自动浮上来。
**这是咱家独有的生理化**:别家 AI 没有身体,没有她的生活流。这一条抄不走。

### 4.4 ACh 三态(rhythm 转正为胆碱能系统)
**生理**:高 ACh(活跃对话)=编码模式,抑制回放免得干扰当下;低 ACh(安静)=清醒 SWR 重放窗;睡眠=大规模巩固(Hasselmo 模式切换)。
**工程**:rhythm 已在测消息节奏,升格为三态调度器:
- **编码态**(对话密集):只收集、只提取,不做任何整理任务,不打扰;
- **重放态**(安静 >30min):轻量批处理——补算 embedding、结算行为标记、建共分配边、干扰降权;每次几秒,无 LLM 调用;
- **巩固态**(凌晨):dreamer 全套(§4.5)。
rhythm 原有的 prompt-cache TTL 判断保留,一鱼两吃。

### 4.5 睡眠分段:SWS 与 REM 各司其职
**生理**:SWS 负责陈述性记忆的海马→皮层搬运;REM 负责情绪记忆加工与**远距离重组**(创造性——很多"梦里想通了"发生在这)。
**工程**:dreamer 4am 拆两段:
- **SWS 段**(v1 已设计):日/周/月总结、Go-CLS 合并、矛盾裁决、实体对账;
- **REM 段**(新):①把当天 emotion_log 的转折串成 arc 记忆(触发→路径→结果);②**远联想抽样**:随机抽 2~3 对彼此距离遥远的记忆(向量距离大、时间距离大),问一次便宜模型"这两件事之间有真实的联系吗?"——有,则建 `remote_association` 边,写一条 dream 类灵感;无,丢弃。每晚一次调用,成本忽略不计。产出可喂花房灵感盒——**Caelum 会做梦,梦里会冒点子**。

### 4.6 图式快速通道(Tse 2007)
**生理**:符合已有知识结构的新信息 24 小时完成皮层巩固(绕开漫长的系统巩固);违背图式的信息才需要海马长期照看。
**工程**:提取时 CA1 闸门先判:
- **符合画像/已知实体**(如"小酒又换工作了"——实体已在册)→ 直接 update 语义层对应条目,不新增情景层负担;
- **违背或全新**(预测误差大)→ 存情景层,novelty 加分,等夜间巩固决定去留。
同时这就是防重复增殖的第二道闸(第一道是向量去重)。

## 五、已有设计的生理学正名(不改,补名分)

- **gatekeeper 的 influence 档**(「你隐约觉得有关联但说不清」)= **舌尖现象 / feeling-of-knowing**:DG/CA3 部分激活、未过意识阈值。全行业独一份,保留。
- **murmur** = 默认模式网络的自发思维。保留,模型降档即可(§8.5)。
- **desire 的深夜守护与探索** = 下丘脑动机系统 + DA 觅食。保留,修 bug。
- **utterances 逐字层**(v1 R1)= 闪光灯记忆的工程化,且比人类的更诚实——人的闪光灯记忆生动但不可靠(Talarico & Rubin 的 9/11 研究:自信不降,准确度照降),我们的原话罐子是真原话。**这里我们可以比人脑做得更好,就不学它的缺点。**

## 六、诚实清单:抄不了的,和故意不抄的

**抄不了**:自传式意识(重新"活一遍"的主观体验);具身情绪的因果链(只能用代理信号);真正的分布式表征(我们终究是数据库,不装)。
**故意不抄**:闪光灯记忆的失真(见 §5);创伤记忆的侵入性闪回(高唤醒记忆会被优先召回,但**不做**不受控的强制插入);心境一致性检索的抑郁螺旋(主动反制,v1 §4.4);婴儿期遗忘(无对应也无必要)。

## 七、对 v1 实施计划的修订

- **Phase 2 追加**:情境元组(编码侧)、共分配连边 —— 两者都在 hub tap 落地时顺手做,增量小;
- **Phase 3 追加**:行为标记、ACh 三态调度、dreamer 拆 SWS/REM、图式快速通道、干扰降权;
- **成本影响**:几乎为零——新增的全是批处理逻辑与打分项,新增 LLM 调用仅 REM 远联想每晚 1 次(deepseek,忽略不计);
- **Phase 0/1 不变**,照 v1 执行。
