# 教程写作规范 · 小兔兔体 🐰

> 兔兔钦定：以后所有面向他人的教程，都用这个风格写。
> 萌是外壳，硬核技术事实是内核——两者都不能少。

## 三个角色 / 元素

| 元素 | 谁 | 干嘛 |
|---|---|---|
| 🐰 **小兔兔** | 好奇的提问者 | 一路「哇哇哇」追问，带着读者的节奏走；会急、会呜呜呜、会挠头，很有情绪 |
| 🧑‍🏫 **讲解** | 耐心的回答者 | 每个问题都答清楚，口语、温柔、带点俏皮 |
| 📦 **技术事实** | 严肃盒子 | 每一环后面挂一个，放**照着敲就能跑**的真代码/命令/步骤/表格 |

## 写作要点

1. **对话推进**：用小兔兔的提问当章节分隔，一问一答往前走，别堆大段说明。
2. **小兔兔要有情绪**：「哇！」「呜呜呜找不到！😖」「好烦人啊！😩」「(挠头)」——越鲜活越好。
3. **技术事实必须真实可用**：代码对着真实实现核对，别写伪代码糊弄；密钥/邮箱/域名一律用 `<占位符>`。
4. **踩坑要讲**：真实踩过的坑最值钱，讲清「现象 → 原因 → 修法」，能配排查表更好。
5. **巧妙之处要点出来**：做得妙的设计（比如"把整条链包成一个工具"）单独开一段讲，别埋没。
6. **结尾一句话精髓** + 一句温暖的祝福。

## 排版（HTML 版）

- 粟粟风：暖奶白背景、奶白卡片、薄荷绿点缀、深色代码框
- 🐰 气泡浅薄荷绿、🧑‍🏫 气泡奶白、📦 技术块左侧薄荷绿边 + chip 标签
- 链接做成薄荷绿下划线（别用默认蓝）
- 自包含单文件（内联 CSS，无外部依赖），手机友好

## 发布流程（三处同步）

1. **VPS 网页**（即时公开）：`/var/www/tutorials/xxx.html` → `https://blossom.amberrib.com/xxx`
2. **主仓库存档**：`docs/xxx.html`
3. **独立 public 仓库 + GitHub Pages**：`caelumbunny-bot/<repo>` → `caelumbunny-bot.github.io/<repo>/`
   （私有主仓库开不了免费 Pages，所以教程单独放 public 仓库，不含 App 代码）
