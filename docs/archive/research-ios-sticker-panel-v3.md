# Research: iOS 贴纸面板 v3（粟粟手绘版）

## 布局（从上到下）

```
┌─────────────────────────────┐
│       对话消息区域            │
│                             │
│                             │
├─────────────────────────────┤
│ 🎨 ○ ○ ○ ▢        ⌨️      │  ← 工具栏（胶囊）
├─────────────────────────────┤
│  ─── 拖拽条 ───             │  ← 毛玻璃面板
│                             │
│   🐕  🐱  📝  🎨           │  ← 贴纸网格
│   ○   ○   ○   ○            │
│                             │
└─────────────────────────────┘
```

## 切换流程

1. 普通：输入框在底部
2. 点贴纸按钮 → 输入框向下收起 → 工具栏 + 贴纸面板从下弹上来
3. 点工具栏上的键盘按钮 → 工具栏 + 面板收回 → 输入框弹回来

## 工具栏内容
- 左侧：贴纸按钮（实心，当前激活态）/ 便签 / 画画
- 右侧：键盘按钮 ⌨️（点了收回面板）

## 贴纸面板
- 毛玻璃材质（.ultraThinMaterial）
- 顶部拖拽条（小横杠）
- 4 列贴纸网格，可滚动
- 贴纸可拖拽到对话区域

## 实现

CardFlowView iOS safeAreaInset：
```swift
if showStickerPanel {
    VStack(spacing: 0) {
        StickerToolbarIOS(...)   // 工具栏
        StickerGalleryPanel(...) // 毛玻璃贴纸面板
    }
} else {
    ChatInputBar(...)
}
```

贴纸按钮位置：输入框下方模型选择器那一排旁边。
