# Research: 记忆面板 — 让 AUDN 可见

## 核心命题

记忆宫殿的灵魂是"AI 记住你"。AUDN 系统已经搭好骨架，但：
1. **用户完全感知不到** — 记忆默默注入 system prompt，没有可视化
2. **数据库几乎是空的** — 只有 1 条测试记忆（"。。"），提取引擎没有真正工作
3. **管理 UI 藏在设置里** — 需要打开设置 → 记忆 tab，不是日常可见的

这三个问题要一起解决。

---

## 现状全景

### AUDN 提取流程（已实现，但效果存疑）

```
用户发消息 → AI 回复 → extractMemoriesIfNeeded()
                            ↓
                    取最近 5 条消息
                    取 hot+warm 记忆
                    选最便宜的模型（haiku/gpt-4o-mini/deepseek）
                            ↓
                    LLM 分析 → JSON { actions: [add/update/delete] }
                            ↓
                    执行 actions → Memory 写入 SwiftData
```

**为什么数据库是空的？** 可能原因：
- 提取模型选择失败（没有配置便宜模型的 API key）
- JSON 解析 silently fails（错误被吞掉了）
- 从未在这个 profile 上真正聊过天（所有对话都是导入的历史，不触发提取）
- `extractMemoriesIfNeeded` 只在 API 聊天后触发，导入对话不触发

### 衰减引擎（已实现，数学正确）

```
w(t) = decayWeight × exp(-0.1 × t)    // t = 天数

Hot:  w ≥ 0.3   → 自动注入每次对话
Warm: w ≥ 0.05  → 可检索，不自动注入
Cold: w < 0.05  → 归档

每次被注入: decayWeight += 0.2 (max 1.0)
```

时间线举例（初始 weight=1.0，不被访问）：
| 天数 | 有效权重 | 层级 |
|------|---------|------|
| 0 | 1.00 | 🔴 Hot |
| 3 | 0.74 | 🔴 Hot |
| 7 | 0.50 | 🔴 Hot |
| 12 | 0.30 | 🔴 Hot → 🟡 Warm 临界 |
| 23 | 0.10 | 🟡 Warm |
| 30 | 0.05 | 🟡 Warm → 🔵 Cold 临界 |
| 69 | 0.001 | 🔵 Cold（几乎遗忘）|

**这个衰减曲线本身就是一个美丽的可视化素材。**

### 记忆注入（已实现）

- 2000 token 预算
- Hot 记忆按 `weight × log(1 + accessCount)` 排序
- 格式：`- <内容> [偏好/事实/关系/目标/情境]`
- 注入位置：system prompt 中 `[关于用户]` 块

### 现有 UI（Settings 里的列表）

位置：`SettingsView.swift:968-1230`

已有功能：
- 三层分组（hot/warm/cold）
- 每条显示：分类标签 + 时间 + 置顶图标
- 操作：置顶/编辑/删除
- 手动添加记忆
- 提取模型选择器
- 统计（总数/hot/warm/cold/token 用量）

**问题**：藏在设置里，视觉上是普通列表，没有时间感、没有生命感。

## 竞品参考

### ChatGPT Memory
- 简单列表，可开关
- 用户看到的是"ChatGPT knows: ..."
- 无衰减、无分层、无时间维度
- 无法看到记忆的"年龄"或"强度"

### SillyTavern (酒馆)
- Lorebook / World Info 系统
- 关键词触发注入
- 无自动提取、无衰减
- 手动维护为主

### 没有人做的事
**没有人让用户看到记忆在时间中呼吸。** 这是我们的机会。

## 可视化设计方向

### 方向 A: 记忆时间线（Timeline）

```
今天 ──────────────────────── 69 天前
 │                              │
 🔴 "粟粟喜欢暖奶白配色"         🔵 "粟粟在研究向量数据库"
 ██████████████████░░░░░░░      ░░
 w=0.95                         w=0.02
 
 🔴 "粟粟叫用户'你'，AI叫'小雾'"
 ████████████████░░░░░░░░░░░
 w=0.82
```

- 横轴是时间，纵向是记忆条目
- 每条记忆是一个渐变条，颜色从 Hot 红 → Warm 黄 → Cold 蓝
- 条的长度/亮度表示衰减权重
- 被访问时闪烁一下（reinforcement 可视化）
- 实时衰减：每次打开面板，权重根据当前时间重新计算

### 方向 B: 记忆星图（Constellation）

- 每条记忆是一颗星
- 亮度 = 衰减权重
- 大小 = accessCount
- 颜色 = category（偏好/事实/关系/目标/情境）
- 星星会随时间慢慢变暗
- 被 AI 提及时闪亮
- hover 看详情，click 编辑

### 方向 C: 记忆河流（最简方案，先做这个）

侧边栏或右面板，列表形式但有生命感：

```
┌─ 记忆 ──────────────────────┐
│                              │
│  🔴 Hot (3)                  │
│  ┌────────────────────────┐  │
│  │ 粟粟喜欢暖奶白配色     │  │
│  │ ████████████░░ 0.95    │  │
│  │ 偏好 · 7次 · 3天前     │  │
│  └────────────────────────┘  │
│  ┌────────────────────────┐  │
│  │ AI叫小雾，用户叫你      │  │
│  │ █████████░░░░ 0.82     │  │
│  │ 事实 · 12次 · 5天前    │  │
│  └────────────────────────┘  │
│                              │
│  🟡 Warm (2)                 │
│  ┌────────────────────────┐  │
│  │ 粟粟在做记忆宫殿项目    │  │
│  │ ████░░░░░░░░ 0.15      │  │
│  │ 事实 · 2次 · 20天前    │  │
│  └────────────────────────┘  │
│                              │
│  🔵 Cold (1)                 │
│  ┌────────────────────────┐  │
│  │ 讨论过椰树椰汁设计      │  │
│  │ ░░░░░░░░░░░░ 0.03      │  │
│  │ 情境 · 1次 · 40天前    │  │
│  └────────────────────────┘  │
│                              │
│  [+ 手动添加记忆]            │
│  ──────────────────────────  │
│  🧠 2000 token 中已用 850   │
│  ████████░░░░░░░░░░░░░░░    │
└──────────────────────────────┘
```

每条记忆卡片有：
- **衰减进度条** — 实时计算的 effectiveWeight，薄荷绿渐变到灰色
- **分类标签** — 偏好/事实/关系/目标/情境，彩色小标签
- **访问次数 + 上次访问** — "7次 · 3天前"
- **操作** — hover 显示编辑/删除/置顶
- **token 预算条** — 底部显示 2000 token 里用了多少

### 我的建议：先做方向 C（河流），再迭代到 A 或 B

方向 C 改动最小（基于现有 SettingsView 里的列表升级），可以独立放在右侧面板或侧边栏。
方向 A/B 需要自定义绘图（Canvas/Metal），更适合后续版本。

## 第零步：先让 AUDN 真正工作

数据库只有 1 条垃圾记忆。在做可视化之前，必须确保：

1. **提取流程调通** — 检查为什么 `extractMemoriesIfNeeded` 没有产出记忆
2. **导入对话也能提取** — 现有 20 万条消息是金矿，应该支持批量回溯提取
3. **手动添加畅通** — 确保 UI 上手动添加记忆正常工作

不然做出来的记忆面板是空的，和没做一样。
